# DPT imaging skills

For imaging questions, start with [dpt-navigator](skills/dpt-navigator/SKILL.md). It selects calibrated pose recovery, ordinary-radiograph matching, viewpoint planning or rendering from the user's goal and available inputs.

Canonical skills are in `skills/`. Git checkouts also provide discovery links in `.agents/skills/`; source archives use this file as their entry point. Run example commands from the source root and use the input, output and budget contracts in the selected skill. Keep user datasets and generated runs outside tracked source files.
